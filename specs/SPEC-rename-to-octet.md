# Spec: Rename App Identity from NetSim-Flow / netsimflow to Octet

**Branch:** `chore/rename-to-octet`
**Spec file:** `specs/SPEC-rename-to-octet.md`
**Status:** ready-for-implementation

---

## Goal

The application is being rebranded from "NetSim-Flow" / "netsimflow" / "NetSimWeb" to "Octet". This spec replaces every occurrence of the old name strings across source code, config files, package manifests, and documentation. The result is a codebase where the product is consistently called "Octet" with slug `octet` and package scope `@octet/`.

---

## Rename Mapping

Apply these substitutions everywhere. The order in this table matters — apply longer/more-specific strings first to avoid double-substitution.

| Old string | New string | Where it appears |
|---|---|---|
| `NetSim-Flow` | `Octet` | Display name in UI, docs, API title, reports |
| `NetSimWeb` | `Octet` | Display name variant in docs |
| `@netsimflow/` | `@octet/` | Package scope in imports and package.json |
| `netsimflow-api` | `octet-api` | Python package name in pyproject.toml |
| `netsimflow-v1` | `octet-v1` | Export format version literal |
| `netsimflow.authToken` | `octet.authToken` | localStorage key |
| `netsimflow_node_id` | `octet_node_id` | GNS3 metadata key |
| `netsimflow_base_type` | `octet_base_type` | GNS3 metadata key |
| `netsimflow_role` | `octet_role` | GNS3 metadata key |
| `.netsimflow.json` | `.octet.json` | Export file extension constant |
| `.netsimflow.md` | `.octet.md` | Export file extension constant |
| `.netsimflow.pdf` | `.octet.pdf` | Export file extension constant |
| `.netsimflow.doc` | `.octet.doc` | Export file extension constant |
| `netsimflow` | `octet` | All remaining lowercase occurrences (package names, DB name/user, emails, slugs) |
| `netsim-flow` | `octet` | Root package.json name field |

**Capitalization rules:**
- Display / title: `Octet`
- Package scope: `@octet/`
- Slug / id / db / package name: `octet`
- Python package: `octet-api`

## Scope

**In scope:**
- All `.ts`, `.tsx`, `.py`, `.json`, `.toml`, `.yml`, `.yaml`, `.md`, `.env` files in the repo (excluding `node_modules/`, `pnpm-lock.yaml`, `.venv/`, `dist/`)
- Package names, workspace references, and import paths
- Database user/name/connection strings in config and env files
- Display strings in UI components and generated reports
- Export format version literals
- Dev email addresses (e.g. `dev@netsimflow.local` → `dev@octet.local`)
- localStorage key in `authToken.ts`
- GNS3 node metadata keys in `gns3.py`
- All documentation files (`AGENTS.md`, `ARCHITECTURE.md`, `README.md`, `MANUAL_TESTING.md`, `NetSim-Flow_Planning_Document.md`)
- `.claude/commands/spec.md` and `.claude/settings.local.json`

**Out of scope (do not change):**
- The repo directory name `NetSimWeb` — this is a filesystem path, not an app name
- The filename `NetSim-Flow_Planning_Document.md` — change content only, not the filename
- `pnpm-lock.yaml` — this will be regenerated by running `pnpm install`
- Anything inside `node_modules/` or `.venv/`
- `dist/` build output — will be regenerated
- The GNS3 server URL or GNS3 template IDs — those are external system identifiers
- The `specs/` directory content itself

## Implementation Steps

Complete these steps in order. Do not skip steps. Do not combine steps.

**IMPORTANT:** You are on Windows. All PowerShell commands below use `(Get-Content ...) -replace 'old','new' | Set-Content ...` for in-place file edits. Run each command exactly as written.

### Step 1 — Rename root package.json

**File:** `package.json` *(modify)*

